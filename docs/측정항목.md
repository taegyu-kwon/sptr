# 측정 항목 분류

지금 앱이 받는 측정 항목 전체 34개와 입력 주체(결정필요 3번).
필요 없는 항목은 메모에 "삭제", 새로 필요한 항목은 맨 아래에 추가한다.

**결정 3 (2026-10-03): 34개 모두 감독·코치가 입력한다. 선수·학부모는 보기만 한다.**

**앱 반영 (2026-11-21, 로컬):**
- 신체·운동능력·실전 25개 — 코치가 **선수 상세(`/c/players/:id`) › 측정 기록**에서 측정일과 함께 추가·수정·삭제.
- SBI/SMI 9개 — 코치가 **SBI/SMI 상세(`/c/sbi/:id`) › 측정값 입력**에서 저장(이력 보관).
- 선수·학부모 — **측정 기록(`/p/input`)**과 **SBI / SMI(`/sbi`)**에서 보기만. `/sbi`의 "가상 입력해 보기" 계산기는 저장되지 않는다.
