# 기능 목록서

SPTR 앱이 **지금 실제로 무엇을 하고 무엇을 못 하는지**를 한 줄씩 적은 문서.
기능을 바꿀 때마다 해당 줄의 상태와 "바뀐 날"을 함께 고친다. 왜 바꿨는지는 `변경기록.md`에 적는다.

기준일: 2026-10-02 · 화면 19개 · 동작 124줄

## 요약

| 상태 | 줄 수 | 뜻 |
|---|---|---|
| 실제 동작 | 103 | 입력하면 저장되고 다른 화면에 반영된다 / 보여주는 데이터를 앱 안의 누군가가 입력할 수 있다 |
| 예시 데이터 | 1 | 화면은 있지만 보여주는 데이터를 앱 안 어디에서도 입력할 수 없다 |
| 가짜 | 4 | 동작하는 척만 한다. 데모 편의 기능 포함(출시 전 제거) |
| 없음 | 16 | 필요한데 화면에 없다 |

> **가장 중요한 한계:** "실제 동작"도 전부 **이 브라우저에만** 저장된다. 다른 기기·다른 브라우저와 공유되지 않으므로, 코치가 발급한 가입 코드로 선수가 자기 휴대폰에서 가입할 수 없다. 서버 연결(로드맵 2단계)로 해결한다.

- 바뀐 날: `MVP` = 7월 제작본 그대로, 날짜 = 그날 동작이 생기거나 바뀜(디자인·문구만 바뀐 건 제외).
- 점수·등급·리스크가 무엇으로 계산되는지는 `계산기준.md`, 제품 주인이 정해야 할 것은 `결정필요.md`.

## 알려진 문제

고치지 않고 남겨 둔 문제와 언제 해결할지. 해결하면 줄을 지우고 `변경기록.md`에 남긴다.

| 문제 | 영향 | 해결 시점 |
|---|---|---|
| 데이터가 기기(브라우저)마다 따로 저장됨 | 코치가 등록한 선수·발급한 코드·피드백이 선수 기기에 없음. 선수가 다른 기기에서 가입 불가. 같은 코드로 다른 브라우저에서 또 가입 가능 | 2단계(서버) |
| 비밀번호가 평문으로 브라우저에 저장됨 | 개발자 도구로 모든 계정의 비밀번호가 보임 | 2단계 |
| 로그인 상태를 사용자 id 문자열 하나로 유지 | 브라우저 저장값만 바꾸면 비밀번호 없이 다른 계정(코치 포함)으로 들어가짐 | 2단계 |
| 로그인 오류 문구가 "등록되지 않은 이메일"과 "비밀번호 틀림"으로 나뉨 | 이메일 가입 여부가 드러남 | 2단계 |
| 역할별 데이터 구분이 화면에서만 됨 | 선수 브라우저에도 팀 전체 측정 기록·다른 계정 정보가 들어 있음. "신체 등급 비공개"도 종합 점수로 역산 가능 | 2단계 + 결정필요 10 |
| 같은 브라우저의 여러 탭이 서로 덮어씀 | 나중에 저장한 탭이 앞 탭의 변경을 지움 | 2단계 |
| 선수를 이름으로 가입 코드·계정에 연결 | 동명 선수가 생기면 가입·이름 수정·삭제가 엉뚱한 선수에 적용될 수 있음(등록·수정 모두 중복 이름은 막아 둠) | 2단계(선수 자체에 연결) |
| 이름 수정·선수 삭제가 로그인 중인 화면에 바로 반영되지 않음 | 새로고침 전까지 예전 이름·삭제된 계정으로 보임 | 2단계 |
| 예시 선수의 SBI 값은 지워도 앱을 열면 다시 채워짐 | 예시 데이터를 걷어낼 때 함께 정리해야 함 | 2단계(예시 데이터 제거) |
| 이닝을 소수로 입력·합산 | 5⅓이닝을 야구 표기대로 "5.1"이라 쓰면 5.1이닝으로 계산되어 ERA가 틀림 | 결정필요 15 후 바로 |
| 다가오는 일정 예시 3건이 2026년 7월 날짜 | 지난 일정이 "다가오는 일정"으로 보임 | 3단계(일정 입력 화면) |
| 시즌 기록 제목 "2026" 고정 | 연도 구분 없이 팀 전체 경기를 합산 | 3단계 |
| 같은 계산이 여러 곳에 따로 있음(SBI/SMI 공식 3곳, 타율·ERA 2곳) | 한 곳만 고치면 화면마다 값이 달라짐 | 계산 기준 확정 후(결정필요 8) 하나로 합침 |
