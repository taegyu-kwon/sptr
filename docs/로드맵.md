# 로드맵

SPTR을 예시 데이터 앱에서 실제 팀이 쓰는 앱으로 만드는 순서. 단계마다 끝나는 기준이 있고, 기준을 태규님이 확인해야 다음 단계로 넘어간다.
요청이 오면 먼저 이 문서의 어느 항목인지 확인하고, 없으면 여기에 추가한 뒤 작업한다.

**지금 위치: 1단계 마무리 중 + 3단계 화면 일부를 로컬(서버 없이)로 먼저 구현** (2026-11-21 개발 재개 — 스포티어 통합 결정 철회, SPTR을 끝까지 완성)

2026-11-21에 3단계의 빠진 화면(측정 입력, 팀 관리·가입 코드, 보관·복원, 수정 기능, 내 계정)을 브라우저 저장만으로 먼저 만들었다. 2단계(서버 연결)는 아직 시작 전이라, 이 기능들도 한 브라우저 안에서만 이어진다. 2단계에서 같은 화면을 서버에 연결한다.

## 3단계 — 빠진 화면 채우기
`사용흐름.md` 3·4장 기준.

표시: `[x] (로컬 구현 …)` = 화면과 동작은 됐지만 이 브라우저에만 저장. 다른 기기와 이어지는 것은 2단계.

**시범 운영에 필수**
- [ ] 팀 관리(관리자): 팀 만들기·설정, 감독 코드 — 2단계 6과 겹침. **팀 이름·지역 수정만** 로컬 구현(2026-11-21, 코치의 팀 관리 화면). 팀 만들기·관리자 역할·감독 코드는 없음
- [ ] 이메일 확인, 비밀번호 재설정 — 2단계 5와 겹침(서버가 있어야 함)
- [ ] 코치진 관리(감독): 코치 코드 발급·해제 — 코치 목록·코치 코드 발급·폐기는 로컬 구현(2026-11-21). **코치 계정 해제**와 감독 전용 권한은 없음
- [x] 가입 코드 현황: 선수별 본인·학부모 코드, 가입 여부, 만료일, 재발급 (로컬 구현 2026-11-21, 서버 연결은 2단계 6 — 감독·야구부장 전용 권한도 2단계)
- [ ] 자녀 선택(학부모, 형제가 있을 때) — 학부모 가입 자체는 로컬 구현(2026-11-21), 형제 연결은 없음
- [x] 선수 삭제 → 보관(졸업·이적), 보관 선수 보기·복원 (로컬 구현 2026-11-21, 서버 연결은 2단계 8)
- [x] 다가오는 일정 입력·수정·삭제 — 월간 일정(경기·대회)과 훈련 공지가 대신함 (로컬 구현: 추가·삭제 2026-11-05, 수정·결과 입력 연결 2026-11-21, 서버 연결은 2단계 8)
