## 2026-10-02 — 0단계: 현재 상태 문서화
- 문서 추가: `기능목록.md`(화면 19개·동작 124줄의 상태), `계산기준.md`(점수·등급·리스크·SBI·라인업 계산식), `결정필요.md`(정해야 할 정책 15건), 이 변경 기록.
- GitHub 비공개 저장소에 백업.
- 문서화 중 찾은 버그 4건 수정:
  - **데이터 입력:** 보이지 않는 탭에서 비운 칸이 빈 값으로 저장되어 점수 계산이 깨지던 문제 → 저장 전 세 탭을 모두 검사하고, 빈 칸이 있으면 그 탭으로 옮겨 알림.
  - **선수 정보 수정:** 이름 중복 검사가 없어 동명 선수가 생기면 가입 코드가 엉킬 수 있던 문제 → 등록 때처럼 같은 이름을 막음.
  - **추천 라인업:** 주석은 "상위 타자를 중심타선에"인데 실제로는 1위 타자가 6번에 들어가던 문제 → 1~3위를 3·4·5번에 배치.
  - **시합 기록 ERA:** 이닝 0인 투수가 ERA 0.00으로 랭킹 1위가 되던 문제 → ERA 랭킹에서 제외, 누적 표에서는 "-".

## 2026-09-16 — 입력이 막혀 있던 세 곳 (75c710d)
화면은 있었지만 실제로 데이터를 넣을 수 없던 곳을 입력 가능하게 함.
- **SBI/SMI 측정 저장**: 선수 계정의 계산기에서 측정값 9개를 저장. 코치 SBI/SMI 리스트·상세에 측정일 표시.
- **시합 기록 입력**: 코치가 경기(날짜·상대·점수·타격·투구 기록)를 등록·삭제. 승패는 점수로 자동 판정.
- **선수단 관리**: 코치가 선수를 등록(가입 코드 자동 발급)·수정·삭제. 선수 상세에 가입 코드와 계정 연결 상태 표시.
- 새 선수는 측정 기록이 없으면 점수 계산이 안 되므로 나이·키·몸무게 외 항목을 기본값으로 채운 첫 측정 기록을 자동 생성.
