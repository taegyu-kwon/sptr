## 2026-11-22 — 서버 연결(Supabase 서버 모드)
커밋 `7cf4473`(SQL·계약서)·`126dfef`(앱). 같은 날 실제 Supabase 프로젝트에 SQL을 적용하고 실서버로 확인했다.

- **서버 모드 동작:** 로그인하면 내 팀 데이터를 전부 읽어 지금 화면이 쓰는 모양으로 만들고, 저장하면 화면을 먼저 고친 뒤 바뀐 행만 서버에 쓴다. 서버 쓰기가 실패하면 화면을 되돌리고 오류 알림. 창에 다시 포커스가 오거나 60초마다 다시 읽어 다른 기기의 변경을 반영. 화면 파일(`src/pages/**`)은 거의 그대로이고 `src/lib/remote.ts`·`sync.ts`·`supabase.ts`가 새로 생김.
- **로그인 화면:** 탭 3개(로그인 / 회원가입 / 새 팀 시작). 회원가입은 가입 코드를 서버에 확인한 뒤 계정을 만들고 코드를 사용 처리. **새 팀 시작**은 계정과 팀을 함께 만들고 "예시 데이터로 시작 / 빈 팀으로 시작"을 고른다. 로그인은 됐지만 팀이 없는 계정에는 "팀에 가입해 주세요"(가입 코드 입력 / 새 팀 시작) 화면. 체험용 가입 코드 2개를 화면에 공개하던 것은 없앰.
- **서버:** 테이블 14개(`supabase/migrations/001_schema.sql`), 권한(RLS)과 판단 함수(`002_rls.sql`), 가입 코드·팀 만들기 함수 4개(`003_functions.sql` — `peek_signup_code`·`redeem_signup_code`·`create_team`·`my_account`), 되돌리기 `rollback.sql`, 권한 검사 `tests/rls_check.sql`. 앱과의 약속은 `supabase/CONTRACT.md`. 권한은 코치(읽기·쓰기) / 선수 본인(읽기 + 자기 출석·공지 읽음) / 학부모(읽기만) 세 가지이고, 보관된 선수의 계정은 팀 데이터를 읽지 못한다.
- **`DB설계.md`와 다른 점:** 설계의 25개 테이블 대신 14개로 줄이고 중첩 배열(타격·투구 줄, 라인업 타순, 공지 시간표, 특이사항, SBI 이력)은 jsonb 로 두었다. 역할 6개·서버 점수 계산·관리자 전용 팀 만들기는 아직 없다. 차이 요약은 `DB설계.md` 맨 위.
- **실서버 확인(2026-11-22):** 새 팀 시작(예시 데이터) → 명단 24명·전 메뉴 → 새로고침 뒤 로그인 유지 → 본인·학부모 코드 발급 → 다른 브라우저에서 선수 가입 → 같은 코드 재사용 거부 → 코치의 측정 추가·공지 수정이 선수 쪽에 반영 → 선수의 출석 체크·공지 열람이 코치 쪽에 반영 → 학부모 가입(쓰기 버튼 없음, 서버도 쓰기 거부) → 선수 보관(명단·계정 차단) → 로그아웃·재로그인 → 비밀번호 변경까지 16단계 통과. 팀 정보·내 이름 수정, 피드백 삭제, 코드 재발급, 측정 기록 삭제, 빈 팀으로 시작, 팀 없는 계정 화면, 저장 실패 되돌리기도 확인. 예시 데이터 올리기는 약 8초(쓰기 요청 12건). 체험 모드는 서버 호출 0건. 390px 로그인 화면(탭 3개·새 팀 시작 흐름) 가로 넘침 없음. 이 확인에서 앱 코드는 고칠 것이 없었다.

## 2026-11-21 — 화면에 보이는 기능을 실제 동작하게, 팀을 배명고등학교로 (로컬, 서버 없음)

- **팀 변경:** 예시 팀을 성남중학교에서 **배명고등학교 야구부**(서울 송파)로(결정 25). 예시 선수 나이 16~18세, 상대팀·대회는 서울권 고교. 점수 기준·SBI는 U15(중학) 그대로 — 결정필요 26.
- **측정은 감독·코치 입력(결정 3 반영):** 코치가 선수 상세에서 측정 기록(신체·운동능력·실전)을 측정일과 함께 추가·수정·삭제. 선수 `/p/input`은 보기 전용 "측정 기록"으로 바뀜. 마지막 1개 기록은 삭제 불가.
- **SBI/SMI:** 코치가 SBI/SMI 상세에서 측정값 9개를 저장, 저장할 때마다 이력(`sbiHistory`)에 쌓임(같은 측정일은 교체), 이력 삭제. 선수 `/sbi`는 결과·이력 보기 + 저장되지 않는 "가상 입력해 보기". 리스트 순위는 측정한 선수끼리만.
- **시합 기록:** 경기 수정, 2루타·3루타·득점·볼넷·삼진·피안타 입력칸, 경기 목록 접힘(10경기씩 더 보기). 시즌 전적·선수 누적·랭킹은 올해 경기 기준.
- **월간 일정:** 경기·대회 수정, 삭제 전 확인. 경기 당일부터 "결과 입력"으로 시합 기록과 연결(`scheduledGameId`), 연결된 경기는 일정에 승패·점수 표시.
- **훈련 공지:** 훈련 항목 수정, 선수가 공지를 열면 읽음 기록(`reads`) — 코치 화면에 확인 인원과 미확인 선수. 공지가 수정되면 다시 미확인.
