계약된 팀 전용 웹앱 MVP입니다. 선수/학부모와 코칭스태프가 분리 회원가입하며, 팀에 제공된 개별 가입 코드로만 가입할 수 있습니다.

## 페이지 구성

### 선수 / 학부모
1. 로그인 / 회원가입 (본인인증 + 개별 가입 코드)
2. 분야별 데이터 입력 (신체 / 운동능력 / 실전)
3. 선수 본인 분야별 능력치 (점수·등급, 훈련 우선순위, 리스크 체크, 성장방향 피드백)
4. 성장·누적 그래프 (분야별 코멘트)
5. 팀 내 전체 순위 (신체 등급 비공개)
6. 코칭스태프 피드백 (개인 + 팀 전체)
7. 팀 플랜 (훈련 일정, 예정 시합, 예상 라인업)

### 코칭스태프
1. 로그인 / 회원가입
2. 팀 내 선수 프로필 (개별 선수 데이터 전체 열람)
3. 분야별 팀 내 선수 랭킹 (포지션 필터)
4. 라인업 시뮬레이션 (전력 계산, 저장 시 선수단에 공개)
5. 팀 피드백 (개인 / 팀 전체 작성)
6. 포지션별 훈련 일정 관리
7. 시합 기록 (팀 기록, 선수 개별 기록, 부문별 랭킹)

## 데모 계정

| 역할 | 이메일 | 비밀번호 |
|---|---|---|
| 선수/학부모 | player@sptr.demo | demo1234 |
| 코칭스태프 | coach@sptr.demo | demo1234 |

데모 가입 코드: `SPTR-PLAYER-01`, `SPTR-PLAYER-02`, `SPTR-COACH-01`

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드 (dist/)
```

MVP 특성상 데이터는 브라우저 localStorage에 저장됩니다 (서버 없음). 로그인 페이지 하단의 "데모 데이터 초기화"로 초기 상태로 되돌릴 수 있습니다.
