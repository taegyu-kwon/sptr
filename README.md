# SPTR — 중학교 야구부 관리 웹앱

감독·코치가 선수의 측정 기록, 출석, 훈련 공지, 경기 일정과 기록, 라인업, 피드백을 한곳에서 관리하고, 선수와 학부모가 자기 성장과 팀 일정을 확인하는 웹앱입니다.
예시 팀 **배명중학교 야구부**(선수 24명, 지어낸 예시 데이터)로 바로 둘러볼 수 있습니다.

> **지금 상태 (2026-11-22):** 두 가지 모드가 있습니다. **서버 모드**(이메일 로그인)는 서버(Supabase)에 저장되어 코치가 노트북에서 입력한 것이 선수·학부모의 다른 기기에 보입니다. **체험 모드**(체험하기 버튼)는 예전처럼 이 브라우저(localStorage)에만 저장됩니다. 남은 일은 [docs/로드맵.md](docs/로드맵.md).

## 두 가지 모드

| | 서버 모드 | 체험 모드 |
|---|---|---|
| 들어가는 법 | 로그인 화면에서 **로그인 / 회원가입(가입 코드) / 새 팀 시작** | 로그인 화면의 **코치로 체험하기 / 선수로 체험하기** |
| 저장 | 서버(Supabase Auth + Postgres). 브라우저에는 로그인 토큰만 | 이 브라우저(localStorage). 서버를 호출하지 않음 |
| 다른 기기와 공유 | 됨(창에 다시 들어오거나 60초마다 다시 읽어 반영) | 안 됨 |
| 데이터 | 내 팀 것만 — 권한은 서버(RLS)가 막음 | 예시 팀 1개 |
| 표시 | 없음 | 화면 위 "체험 모드 · 이 브라우저에만 저장" 배지 |

서버 모드 사용 순서: 코칭스태프가 **새 팀 시작**으로 팀을 만들고(예시 데이터로 시작 / 빈 팀으로 시작) → **팀 관리**에서 선수 본인·학부모·코치 가입 코드를 발급 → 받은 사람이 **회원가입** 탭에서 코드와 이메일로 가입합니다. 학부모 계정은 보기 전용입니다.

## 체험하기

로그인 화면의 **코치로 체험하기 / 선수로 체험하기** 버튼을 누르면 가입 없이 예시 팀(체험 모드)으로 바로 들어갑니다. 서버에는 아무것도 올라가지 않습니다.

- 체험 모드에서는 회원가입을 해 볼 수 없습니다(로그인·회원가입·새 팀 시작 탭은 서버 모드로 동작합니다). 가입 흐름을 보려면 **새 팀 시작**으로 팀을 만들어 코드를 발급하세요.
- 로그인 화면 아래 **데모 데이터 초기화**를 누르면 체험 모드 데이터가 오늘 날짜 기준의 예시 데이터로 되돌아갑니다.

## 할 수 있는 일

### 감독 · 코치
- **팀 대시보드** — 다음 경기, 시즌 전적, 오늘 출석, 재활·부상 선수, 이번 주 훈련
- **선수단** — 학년·포지션별 명단(카드/표), 선수 등록, 졸업·이적 선수 보관과 복원
- **선수 상세** — 측정 기록(신체·운동능력·실전) 추가·수정·삭제, 점수와 추이, 올해 성적, 출석, 특이사항(재활·부상)
- **SBI / SMI** — 근력·역학 지표 측정값 입력과 측정 이력, 팀 순위
- **시합 기록** — 경기 등록·수정, 선수별 타격·투구 기록, 누적 기록과 부문별 랭킹
- **경기 라인업** — 타순·수비 위치·지명타자, 추천 자동 배치, 선수단 공개
- **팀 캘린더(월간 일정)** — 연습경기·대회 일정 추가·수정, 경기 결과 입력으로 시합 기록과 연결, 월간 훈련 방향
- **훈련 공지** — 날짜별 집합 시간·준비물·조별 시간표, 선수 확인(읽음) 현황
- **출석 관리** — 날짜별 현황 확인과 수정
- **코칭 피드백** — 선수 개인·팀 전체 피드백 작성·수정·삭제
- **새 팀 시작**(서버 모드) — 로그인 화면에서 계정과 팀을 함께 만들고 예시 데이터 또는 빈 팀으로 시작
- **팀 관리** — 팀 정보, 코치진, 가입 코드(선수 본인·학부모·코치) 발급·재발급. 코드는 14일 뒤 만료되는 1회용
- **분야별 랭킹**, **측정 센터 지도**(센터 정보는 예시 데이터)

### 선수 · 학부모
- **내 능력치 · 성장 그래프 · 측정 기록** — 코치가 입력한 측정값과 점수·등급, 추이를 보기 전용으로 확인
- **SBI / SMI** — 내 결과와 이력, 값을 바꿔 보는 가상 계산기(저장되지 않음)
- **팀 내 순위**, **코칭 피드백**
- **팀 캘린더 · 훈련 공지 · 예상 라인업**
- **출석 체크** — 선수 본인이 오늘 출석을 체크하거나 지각·결석을 사유와 함께 신고(학부모 계정은 보기만)
- **내 계정** — 비밀번호 변경

## 아직 안 되는 것

- 이메일 확인(서버에서 꺼 둠 — 아무 이메일로나 가입됨), 비밀번호 찾기
- 감독·야구부장·관리자 역할 구분(지금은 코치·선수·학부모뿐). 팀은 가입한 누구나 만들 수 있음
- 다른 기기의 변경을 실시간으로 받기(60초마다·창에 다시 들어올 때 반영), 오프라인 저장
- 측정 센터의 실제 지도·예약·측정 결과 연동
- 점수 기준과 SBI/SMI는 U15(중학) 기준입니다

화면·동작별 정확한 상태는 [docs/기능목록.md](docs/기능목록.md)에 있습니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입 검사 + 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
```

기술: React 18 · TypeScript · Vite · React Router · Recharts · Supabase(Auth + Postgres, `@supabase/supabase-js`). 체험 모드 데이터는 브라우저 localStorage(`sptr-db-v6`, `sptr-schedule-v4`)에 저장됩니다.

### Supabase 설정

앱은 `src/lib/supabase.ts`에 적힌 프로젝트 주소와 공개용(publishable) 키로 바로 연결됩니다. 다른 프로젝트를 쓰려면 ① Supabase SQL Editor에서 `supabase/migrations/001_schema.sql` → `002_rls.sql` → `003_functions.sql` 순서로 실행하고(여러 번 실행해도 됨, 지우려면 `supabase/rollback.sql`), ② Authentication → Sign In / Providers → Email 에서 **Confirm email 을 끄고**(켜 두면 가입 직후 세션이 없어 가입 코드 사용이 실패함), ③ 환경 변수 `VITE_SUPABASE_URL`·`VITE_SUPABASE_KEY`에 그 프로젝트의 주소와 공개용 키를 넣어 실행합니다. service_role 키는 쓰지 않습니다. 테이블·권한·함수와 앱의 약속은 [supabase/CONTRACT.md](supabase/CONTRACT.md), 권한 검사는 `supabase/tests/rls_check.sql`입니다.
