U15 점수 환산 공식 보기
SBI = (3대 스트렝스 평균 + 버티컬 점프(cm) + 최고 구속(km/h)) ÷ (10m 스프린트(초) × 10) × 5.1

스쿼트 (X = 개수)
X ≥ 50 → 100 | 40~49 → 70+(X−40)×3 | 30~39 → 40+(X−30)×3 | X<30 → X×1.3

외발 데드리프트 (X = 횟수)
X ≥ 13 → 100 | 9~12 → 70+(X−9)×7.5 | 6~8 → 40+(X−6)×10 | X<6 → X×6.5

푸쉬업 (X = 개수)
X ≥ 40 → 100 | 29~39 → 70+(X−29)×2.7 | 20~28 → 40+(X−20)×3.3 | X<20 → X×1.9

학년별 가중 중량 (W = 체중)
중1: 스쿼트 W×0.25 / 데드 총 W×0.30 / 푸쉬업 맨몸
중2: 스쿼트 W×0.33 / 데드 총 W×0.40 / 푸쉬업 +5kg
중3: 스쿼트 W×0.40 / 데드 총 W×0.50 / 푸쉬업 +10kg
